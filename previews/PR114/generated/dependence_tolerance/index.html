Tolerance of the numerical dependence of monomials

In the SVD examples below, atom extraction from a moment matrix and reduction modulo a truncated ideal give a matrix $Z$ with orthonormal columns. Its rows are indexed by monomials. Which rows are linearly dependent on the previous ones?

  • For atom extraction, $Z$ spans the image space of the moment matrix, see image_space. The moment matrix is typically the solution of an SDP solver hence it is only known with the accuracy of the solver.
  • For a truncated ideal, $Z$ spans the null space of the Macaulay matrix of exact equations, see MacaulayNullspace. It is used, e.g., by SumOfSquares to reduce the Gram basis of a Sum-of-Squares certificate over an algebraic set.

In both cases, $Z$ is computed from a singular value decomposition and the dependent monomials are the columns that are not pivots of the reduced row echelon form of $Z^\top$. The Gaussian elimination needs a tolerance below which an entry is considered to be zero. This tutorial studies how to choose this tolerance so that it works for both cases. It explains the choice made in accuracy.

using LinearAlgebra, Markdown, Printf, Random
import GenericLinearAlgebra # `svd` of `Matrix{BigFloat}`
using DynamicPolynomials

import MultivariateMoments as MM
import SparseArrays

Noise and signal

We compute the true pivots by doing the same computation in BigFloat. To make sure the reference is not affected by the round-off errors, the elimination in BigFloat uses a tolerance much smaller than the precision of Float64 but much larger than the precision of BigFloat.

setprecision(BigFloat, 128)

function pivots(A, tol)
    U = copy(A)
    MM.RowEchelon.rref!(U, tol)
    return Set(MM._pivots(U))
end

true_pivots(A::Matrix{BigFloat}) = pivots(A, big(1e-25))
true_pivots (generic function with 1 method)

Given the true pivots, we run the Gaussian elimination by following them instead of comparing the entries with a tolerance. Along the way, we record:

  • the noise: the largest entry of a column that is truly dependent; it should be zero but it is nonzero because of numerical errors,
  • the signal: the smallest pivot of a column that is truly independent.

A tolerance tol gives the true pivots if noise < tol < signal.

function noise_and_signal(A, piv)
    A = copy(A)
    nr, nc = size(A)
    i = 1
    noise = 0.0
    signal = Inf
    for j in 1:nc
        if i > nr
            break
        end
        m, mi = findmax(abs, view(A, i:nr, j))
        mi += i - 1
        if j in piv
            signal = min(signal, m)
            A[[i, mi], :] = A[[mi, i], :]
            A[i, :] ./= A[i, j]
            for k in 1:nr
                if k != i
                    A[k, :] .-= A[k, j] .* A[i, :]
                end
            end
            i += 1
        else
            noise = max(noise, m)
            A[i:nr, j] .= 0
        end
    end
    return noise, signal
end
noise_and_signal (generic function with 1 method)

For each case, the first table gives the number of monomials n, the measured noise and signal, and two ratios. With r the selected rank, ρ₁ = σ[r+1] / σ[1] scales the first discarded singular value by the largest one, and ρᵣ = σ[r+1] / σ[r] scales it by the weakest retained one.

The second table shows which tolerances recover the reference pivots (✓). The first two columns of results use ρ₁/√n (previously used by Echelon) and ρᵣ·√n. Both floor the ratio at machine precision before scaling and apply a single elimination. Gap at r checks for a gap at the selected rank, and First gap uses the first gap at or after that rank. Both call BasisDependence and retry at a lower tolerance if the initial elimination loses rank. For example, a rank-one space spanned by a vector with 128 equal entries has unit norm after normalization, but each entry is only about 0.088. If the proposed tolerance is 0.09, the first pass discards every entry.

function gap_pivots(Z, basis, σ, r; gap_tol = 1e-2)
    return map((false, true)) do search_later
        policy = MM.GapBasedAccuracy(MM.FixedRank(r); gap_tol, search_later)
        null = MM.MacaulayNullspace(Z, basis, MM.accuracy(σ, r, policy))
        d = MM.BasisDependence{MM.LinearDependence}(null)
        return Set(findall(!MM.is_dependent, d.dependence))
    end
end

function row(labels, Z, basis, σ, r, piv)
    A = Matrix(transpose(Z))
    n = size(Z, 1)
    noise, signal = noise_and_signal(A, piv)
    label = join(labels, " | ")
    measurements = @sprintf(
        "| %s | %d | %.1e | %.1e | %.1e | %.1e |",
        label,
        n,
        σ[r+1] / σ[1],
        σ[r+1] / σ[r],
        noise,
        signal,
    )
    recovery = "| $label |"
    for tol in (
        max(σ[r+1] / σ[1], eps()) / sqrt(n),
        max(σ[r+1] / σ[r], eps()) * sqrt(n),
    )
        recovery *= pivots(A, tol) == piv ? " ✓ |" : " ✗ |"
    end
    for found in gap_pivots(Z, basis, σ, r)
        recovery *= found == piv ? " ✓ |" : " ✗ |"
    end
    return (; measurements, recovery)
end

Macaulay null spaces

The Macaulay matrix of degree D of exact equations has entries known up to machine precision so its singular values have a clear gap between the nonzero singular values and the ones that are zero up to round-off errors.

@polyvar x y z

function macaulay(label, equalities, D)
    M = MB.macaulay(equalities, D, [x, y, z])
    A = float(Matrix(SparseArrays.sparse(M)))
    F = svd(A; full = true)
    check = MM._default_nullspace_rank_check(A)
    r = MM.rank_from_singular_values(F.S, check)
    Z = F.Vt[(r+1):end, :]'
    big_A = big.(A)
    ref = svd(big_A; full = true)
    ref_rank = MM.rank_from_singular_values(
        ref.S,
        MM._default_nullspace_rank_check(big_A),
    )
    @assert r == ref_rank
    piv = true_pivots(Matrix(ref.Vt[(ref_rank+1):end, :]))
    return row((label,), Z, M.column_basis, F.S, r, piv)
end

In M3 the equations have very different scales. The noise in the elimination is about 1e-13 even though σ[r+1] / σ[1] is close to machine precision. Scaling by σ[r] gives a larger tolerance.

Wedin bounds the angle between singular subspaces using perturbation or residual norms and the spectral separation of retained and discarded directions. With a pronounced gap at rank r, that separation may be close to σ[r]. Using σ[r+1] as a proxy for the perturbation size then suggests the scale σ[r+1] / σ[r]. An actual angle bound needs independent information about the perturbation. (Wedin, 1972)

Gaussian elimination introduces rounding error and can amplify errors already present in the singular vectors. For partial pivoting, a worst-case backward error bound includes a dimension factor and element growth (Chapter 9). The square-root rule of thumb for accumulated rounding error assumes cancellation of errors of varying signs (Section 2.8). (Higham, 2002)

Average-case experiments show much smaller element growth than the worst-case bound for several random matrix ensembles. (Trefethen and Schreiber, 1990)

Applying these results to dependence decisions requires an additional empirical choice. Here the input may already contain error from an SDP solver. The multiplier √n for the initial pivot tolerance was chosen empirically in pull request #111. The examples below compare the two choices of spectral gap.

For exact equations, the computed σ[r+1] is often below the machine precision. It is not a reliable estimate of the noise since the singular values are only computed with an error of about length(σ) * eps * σ[1], which is the default tolerance of LinearAlgebra.rank. For instance, for the equations x^2 + y^2 / 3 - 0.7 and x * y - y^3 / 7 at degree 6, the computed σ[r+1] / σ[1] changes from 1.0e-16 to 7.4e-17 between Julia v1.13 and v1.15, and the noise of the Gaussian elimination, about 1.9e-15, exceeds σ[r+1] / σ[r] · √n with v1.15. The level of noise used by accuracy is therefore at least length(σ) * eps * σ[1].

Moment matrices with noise

We now consider the moment matrix of atoms lying on a variety so that some monomials are dependent before the last pivot. To mimic the inaccuracy of an SDP solver, the moment matrix is perturbed by a random symmetric matrix of relative norm δ. The rank is fixed to the number of atoms with FixedRank to separate the choice of the rank from the choice of the pivots. The atoms and the true pivots are computed in BigFloat so that roundoff in the reference pivots is small compared with the perturbation.

function moments(vars, d, atoms, δ; case = nothing)
    monos = monomials(vars, 0:d)
    k = length(atoms)
    V = [m(vars => a) for m in monos, a in atoms]
    W = big.(range(1, 2; length = k))
    exact = Float64.(V * Diagonal(W) * V')
    piv = true_pivots(Matrix(transpose(V)))
    E = randn(size(exact))
    E = (E + E') / 2
    M = exact + δ * opnorm(exact) / opnorm(E) * E
    chol = MM.low_rank_ldlt(M, MM.SVDLDLT(), MM.FixedRank(k))
    noise_level = @sprintf("%.0e", δ)
    labels = isnothing(case) ? (noise_level,) : (case, noise_level)
    return row(
        labels,
        chol.L,
        MB.SubBasis{MB.Monomial}(monos),
        chol.singular_values,
        k,
        piv,
    )
end

# Atoms on the circle of radius `radius` with angles `2π i / k + 0.1 i^2` for
# `i = 1, ..., k`
function circle(radius, k)
    return [
        radius .* [cos(t), sin(t)] for
        t in (2big(π) * i / k + big(0.1) * i^2 for i in 1:k)
    ]
end
function sphere()
    u, v = big(π) * rand() - big(π) / 2, 2big(π) * rand()
    return [cos(u) * cos(v), cos(u) * sin(v), sin(u)]
end

Choosing which gap to use

GapBasedAccuracy wraps a rank check. With gap_tol = 1e-2, a gap after j means σ[j+1] < 10⁻² σ[j]. The default, search_later = false, checks only j = r. Setting search_later = true uses the first qualifying gap at or after r. If either policy finds a gap, it divides σ[j+1] by σ[r]. Otherwise it divides σ[r+1] by σ[1]. The numerator includes the roundoff floor described above. A later gap can suggest a noise floor for a larger signal space. Wedin's separation for the chosen subspace is still the separation at rank r. Changing the search range can even increase the tolerance. For example, with σ = [1, 1e-3, 5e-4, 4e-6] and r = 2, the default gives 5e-4. Searching one step further gives 4e-6 / 1e-3 = 4e-3.

A. Spurious coordinate. In the diagonal matrix below, the clean rank-two subspace is spanned by coordinate vectors 1 and 3. A small perturbation couples directions 2 and 3 while leaving the fourth singular value zero.

A = diagm([1.0, 5e-4, 1e-3, 0.0])
A[2, 3] = A[3, 2] = 1e-12
F_coupled = svd(A)

The selected-rank policy skips the spurious 2e-9 component in column 2. Searching for a later gap finds one after the third singular value and sets a tolerance of about 1.8e-12, which accepts that component.

A later gap can help when discarded directions still carry signal, as in the two-atom example. A gap far below the selected rank can also suggest a tolerance small enough to admit roundoff or perturbation in a dependent column, as in the coupled matrix. The clean pivots distinguish these two outcomes even though both policies recover the requested number of pivots.

The first six monomials are already independent. A generic six-dimensional subspace has the same six pivots, so a check mark here says little about recovery of the clean subspace. At higher perturbations the sixth singular direction can be poorly determined.

The gap threshold 10⁻² is heuristic. For the sphere at δ = 1e-4, the fallback can accept spurious pivots. The noise and signal columns show the interval of tolerances that recovers the reference pivots. Once the measured noise exceeds the signal, no single tolerance along this elimination path can recover them all.
